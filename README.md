# Placement Prediction Model 🚀

A simple End-to-End Machine Learning project built with Python that predicts whether a student will get placed based on their **CGPA** and **IQ** scores.

## 🛠️ Tech Stack
* **Language:** Python
* **Libraries:** Scikit-Learn, Pandas, NumPy, Matplotlib, MLxtend
* **Algorithm:** Logistic Regression

## 📊 Dataset
The model uses a student dataset containing three main columns:
* `cgpa`
* `iq`
* `placement` (Target: 1 for Placed, 0 for Not Placed)
